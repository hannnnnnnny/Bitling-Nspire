# Controls

| Input | Action |
|---|---|
| Arrow keys | Move one tile in WORLD; choose menu entries |
| Enter / Return | Open, interact, take a combat turn, advance dialogue |
| Esc | Back; WORLD opens menu; BATTLE cancels submenu |
| Letter M | Open WORLD menu; BATTLE cancels submenu |
| 8 / 2 / 4 / 6 | Alternate up / down / left / right |
| 5 / 0 | Alternate Enter / Back |
| Ctrl+S | TI: save the current game document. Host: write simulator JSON |
| F12 (host only) | Save current 1× image to build/simulator.png |

The TI physical Menu key stays available for TI's commands. Letter M is the game's menu key; no undocumented menu-key callback is assumed.

Stand next to an NPC, node, terminal or cache and press Enter. The footer shows nearby interactions. Tiny amber sparks mark hidden caches. Violet doorway pixels are portals. Ripple tiles can start random fights; ordinary paths are safe.

Battle submenus scroll through every skill/item. Esc returns to Attack/Skill/Item/Run. Invalid or unaffordable actions cost no turn. Analyze primes a damaging action; Graph exposes weaknesses; Debug heals and removes glitch; Factor reduces defense; Solve uses Logic.

The three nodes award XP and fragments. If the Boss is too strong, use a terminal and fight regular enemies for levels. Guard Shell halves the next three damaging enemy turns. After winning, press Enter to return to WORLD and save.

Defeat is recoverable: Enter acknowledges, then Enter at SIGNAL LOST returns to HOME with forest location and restored HP. Quest progress and remaining items persist.
