# Mote MVP implementation plan

Goal: playable stock-Lua Gen 1 RPG/pet, beginning through ending, with verified host behavior and explicit device acceptance limits.

Architecture: same Lua 5.1 modules on TI and host; data-driven systems; TI document save events; primitive sprites.

Constraints: no firmware/Ndless/Python on device, no unrelated document writes, functions under 40 lines, critical paths tested, independent commits.

## Execution tasks

- [x] Core: tools/build.py emits local module registry and src/main.lua callbacks. Tests load via Lupa Lua 5.1. src/core/state.lua supplies complete defaults. Input maps named events. Verify boot and unknown keys. Commit core independently.
- [x] World/content: src/data/maps.lua defines three 16×11 maps; src/world/world.lua exposes move/interact/encounter. Test walls, portals, NPC blocking, each node and hidden cache once, all-object reachability. Commit.
- [x] Progression/items: src/data/items.lua and src/systems/inventory.lua, progression.lua. Test quantities, invalid IDs, item effects, XP rollover/cap. Commit.
- [x] Combat: enemy/skill data, systems/combat.lua. Test all five skills, all six enemies, turn costs, rewards once, run/boss restriction, defeat. Commit.
- [x] Pet: systems/pet.lua + animation.lua and compact pixel data. Test return/win/loss/level/rare/inactivity, cooldown and frame selection. Commit.
- [x] Persistence: core/save.lua with plain versioned tables. Tests roundtrip/missing/malformed/range/blocked spawn/unknown item/quest flags, no active battle serialization. Commit.
- [x] Gameplay: core/game.lua with state router and local dialogue provider, node quest, ending. Test complete input-driven campaign using real modules. Commit.
- [x] Rendering: ui widgets, screens and TI graphics adapter; test paint all states at 320×240 and 318×212, narrow pane notice. Commit.
- [x] Host tools: tkinter/Pillow simulator runs the actual bundled callbacks. JSON atomic saves, no executable data. Render screenshots and execute callback smoke tests. Commit.
- [x] Packaging/docs: build Luna .tns if available, preserve editor fallback. README, INSTALL, CONTROLS, ROADMAP, ASSETS and device acceptance checklist. Run full suite, source checks and frame/memory benchmark. Commit independently.

Test command: python tools/test.py (Lupa Lua 5.1, unittest, no device dependency).
Build command: python tools/build.py; optional --luna path/to/luna executable.
Host play: python tools/simulate.py.

Review: read complete source/diff after passing tests; repair important findings before final delivery. Physical Gen 1 behavior remains unverified without the user's device.
